# Home Assistant 3D Print Calculator

Полнофункциональный 3D-калькулятор для Home Assistant: себестоимость печати, коммерческая цена, скидки, срочные заказы, материалы, склад и профили принтеров.

## Текущая версия

**v1.0.0** — HACS-версия стабильного рабочего калькулятора **V5.1**.

> Локальная установка в Home Assistant на этапе миграции не изменяется и может работать параллельно.

## Возможности

- расчёт себестоимости 3D-печати;
- учёт материала и отходов;
- учёт времени печати;
- электричество, амортизация и расходники принтера;
- упаковка, постобработка и труд;
- розничная цена;
- постоянный клиент со скидкой;
- оптовые скидки по диапазонам количества;
- срочный заказ с дополнительной надбавкой;
- минимальная стоимость заказа;
- округление цены вверх;
- управление материалами;
- складской остаток в граммах и катушках;
- списание материала после расчёта;
- профили принтеров;
- экспорт и импорт данных JSON;
- автоматическое сохранение данных в браузере;
- копирование полного расчёта и цены для клиента.

## Структура

```text
hassio-3d-print-calculator/
├── hassio-3d-print-calculator.js   # HACS entrypoint
├── hacs.json                       # HACS manifest
├── www/
│   └── 3d-calculator-v5.1.js      # стабильная рабочая логика V5.1
├── .github/workflows/release.yml
├── README.md
└── CHANGELOG.md
```

Корневой `hassio-3d-print-calculator.js` является точкой входа HACS и подключает рабочий файл из `www/`. Логика калькулятора при миграции не переписывается.

## Установка через HACS

1. Откройте **HACS → Frontend**.
2. Нажмите меню `⋮` → **Custom repositories**.
3. Добавьте:

```text
https://github.com/menfis911/hassio-3d-print-calculator
```

4. Тип репозитория: **Dashboard**.
5. Установите **3D Print Calculator** версии `1.0.0`.
6. Перезапустите Home Assistant или обновите страницу с очисткой кеша.

### Подключение к `panel_custom`

После установки через HACS используйте HACS-ресурс вместо локального `/local/`-файла:

```yaml
panel_custom:
  - name: three-d-print-calculator
    sidebar_title: 3D Калькулятор
    sidebar_icon: mdi:printer-3d
    url_path: 3d-print-calculator
    module_url: /hacsfiles/hassio-3d-print-calculator/hassio-3d-print-calculator.js
```

На этапе миграции старую конфигурацию и файл `/config/www/3d-calculator-v5.1.js` **не удалять**. Сначала проверить HACS-версию.

## Данные

Калькулятор продолжает использовать существующий ключ `localStorage`:

```text
ha-3d-print-calculator-v2
```

Поэтому перенос JavaScript-файла сам по себе не должен удалять текущие настройки, материалы, склад или расчёт: данные находятся в браузере, а не внутри JS-файла.

## Коммерческая логика

По умолчанию:

- розница: наценка 70%;
- постоянный клиент: скидка 15%;
- опт 2–4 шт.: скидка 5%;
- опт 5–9 шт.: скидка 10%;
- опт 10–49 шт.: скидка 20%;
- опт от 50 шт.: скидка 30%;
- срочный заказ: +30%;
- минимальный заказ: 500 ₽;
- округление: вверх до 50 ₽;
- отходы: 5%.

Все эти параметры можно изменить в настройках калькулятора.

## Версионирование

Проект использует GitHub Releases и semantic versioning.

Первая HACS-версия: `v1.0.0`.

Дальнейшие изменения выпускаются новыми версиями и не требуют изменения рабочей локальной установки до завершения проверки.

## Безопасная миграция

1. Установить репозиторий через HACS.
2. Не удалять старый локальный JS.
3. Подключить HACS-версию к `panel_custom`.
4. Проверить открытие калькулятора.
5. Проверить материалы и склад.
6. Проверить расчёт цены.
7. Проверить копирование.
8. Проверить импорт/экспорт JSON.
9. Только после успешной проверки удалить старый локальный JS.

До завершения проверки старый `/config/www/3d-calculator-v5.1.js` не трогать.
