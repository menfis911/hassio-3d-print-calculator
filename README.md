# Home Assistant 3D Print Calculator

Полнофункциональный 3D-калькулятор для Home Assistant: себестоимость печати, коммерческая цена, скидки, срочные заказы, материалы, склад и профили принтеров.

## Текущая версия

**v1.0.0** — перенос стабильной рабочей версии калькулятора **V5.1** в отдельный GitHub-репозиторий для дальнейшего распространения через HACS.

> В этой версии логика калькулятора сохранена. Локальная установка в Home Assistant не изменяется и может продолжать работать параллельно.

## Возможности

- расчёт себестоимости 3D-печати;
- учёт материала и отходов;
- учёт времени печати;
- электричество, амортизация и расходники принтера;
- упаковка, постобработка и труд;
- розничная цена;
- постоянный клиент со скидкой;
- оптовые скидки по диапазонам количества;
- срочный заказ с дополнительной надбавкой;
- минимальная стоимость заказа;
- округление цены вверх;
- управление материалами;
- складской остаток в граммах и катушках;
- списание материала после расчёта;
- профили принтеров;
- экспорт и импорт данных JSON;
- автоматическое сохранение данных в браузере;
- копирование полного расчёта и цены для клиента.

## Установка

### Важно: текущая локальная установка

На этапе миграции старый локальный файл удалять **не нужно**. Рабочая версия может оставаться установленной в `/config/www/`.

После проверки HACS-версии старую установку можно будет удалить отдельным этапом.

### HACS

Репозиторий предназначен для установки через HACS как custom repository. На первом этапе добавьте:

```text
https://github.com/menfis911/hassio-3d-print-calculator
```

Тип репозитория: **Dashboard**.

После установки файл калькулятора будет находиться в каталоге HACS/frontend. Для подключения его к `panel_custom` потребуется указать URL установленного ресурса.

> Конкретная схема `module_url` зависит от способа, которым HACS установит frontend-файл. Перед удалением локального файла обязательно проверить загрузку и работу калькулятора через HACS.

## Данные

Калькулятор продолжает использовать существующий ключ `localStorage`:

```text
ha-3d-print-calculator-v2
```

Поэтому перенос JavaScript-файла сам по себе не должен удалять текущие настройки, материалы, склад или расчёт: данные находятся в браузере, а не внутри JS-файла.

## Коммерческая логика

По умолчанию:

- розница: наценка 70%;
- постоянный клиент: скидка 15%;
- опт 2–4 шт.: скидка 5%;
- опт 5–9 шт.: скидка 10%;
- опт 10–49 шт.: скидка 20%;
- опт от 50 шт.: скидка 30%;
- срочный заказ: +30%;
- минимальный заказ: 500 ₽;
- округление: вверх до 50 ₽;
- отходы: 5%.

Все эти параметры можно изменить в настройках калькулятора.

## Версионирование

Проект использует GitHub Releases и semantic versioning.

Формат:

```text
MAJOR.MINOR.PATCH
```

Первая HACS-версия: `v1.0.0`.

Дальнейшие изменения планируется выпускать без изменения рабочей локальной версии до момента проверки обновления.

## Безопасная миграция

Порядок миграции:

1. Установить репозиторий через HACS.
2. Подключить HACS-версию к Home Assistant.
3. Проверить калькулятор.
4. Проверить материалы и склад.
5. Проверить расчёт цены.
6. Проверить копирование.
7. Проверить импорт/экспорт JSON.
8. Только после успешной проверки удалить старый локальный JS.

До завершения проверки старый `/config/www/3d-calculator-v5.1.js` не трогать.
