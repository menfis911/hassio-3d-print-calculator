# Home Assistant 3D Print Calculator

Полнофункциональный 3D-калькулятор для Home Assistant для расчёта себестоимости, коммерческой цены, заказов, материалов, склада и принтеров.

## Возможности

### Калькулятор

- расчёт себестоимости печати;
- материал и отходы;
- время печати;
- электричество, амортизация и расходники принтера;
- упаковка, постобработка и труд;
- розница;
- постоянный клиент со скидкой;
- оптовые скидки по количеству;
- срочный заказ;
- минимальная стоимость заказа;
- округление цены вверх;
- цена за единицу, прибыль и маржа;
- копирование полного расчёта;
- копирование цены для клиента;
- списание материала со склада.

### Заказы

- многострочный заказ;
- несколько изделий в одном заказе;
- отдельный материал, принтер, вес, количество и время для каждой позиции;
- сводная себестоимость, цена и прибыль заказа;
- сохранение заказа в историю;
- печать заказа и вывод через системный диалог печати в PDF.

### Материалы и склад

- добавление, изменение и удаление материалов;
- вес катушки и цена;
- остаток в граммах и количество катушек;
- автоматический пересчёт стоимости грамма;
- списание фактического расхода после расчёта.

### Принтеры

- несколько профилей принтеров;
- электричество;
- амортизация;
- расходники;
- автоматический расчёт стоимости часа работы.

### История

- сохранение выполненных расчётов;
- дата и время;
- стоимость;
- прибыль;
- повторное открытие сохранённого расчёта;
- очистка истории.

### Данные

- автоматическое сохранение в браузере;
- экспорт JSON;
- импорт JSON;
- автоматическая миграция ранее сохранённых данных на актуальный ключ хранения;
- пользовательские данные не зависят от обновления HACS.

### Home Assistant

Компонент работает как frontend-панель Home Assistant и публикует браузерное событие `three-d-print-calculator-changed` после изменения данных. Событие содержит актуальные данные и результат расчёта и оставляет возможность для дальнейшей интеграции с Home Assistant.

## Установка через HACS

1. Откройте **HACS → Frontend**.
2. Нажмите `⋮` → **Custom repositories**.
3. Добавьте репозиторий:

```text
https://github.com/menfis911/hassio-3d-print-calculator
```

4. Тип репозитория: **Dashboard**.
5. Установите **3D Print Calculator**.
6. Перезапустите Home Assistant или обновите страницу с очисткой кеша.

### Подключение к `panel_custom`

```yaml
panel_custom:
  - name: three-d-print-calculator
    sidebar_title: 3D Калькулятор
    sidebar_icon: mdi:printer-3d
    url_path: 3d-print-calculator
    module_url: /hacsfiles/hassio-3d-print-calculator/hassio-3d-print-calculator.js
```

## Коммерческая логика

Значения по умолчанию:

- розница: наценка 70%;
- постоянный клиент: скидка 15%;
- опт 2–4 шт.: скидка 5%;
- опт 5–9 шт.: скидка 10%;
- опт 10–49 шт.: скидка 20%;
- опт от 50 шт.: скидка 30%;
- срочный заказ: +30%;
- минимальный заказ: 500 ₽;
- округление: вверх до 50 ₽;
- отходы: 5%.

Все параметры можно изменить в настройках.

## Версионирование

Проект использует semantic versioning: `MAJOR.MINOR.PATCH`.

- `PATCH` — исправления и небольшие изменения;
- `MINOR` — новые функции;
- `MAJOR` — крупные или несовместимые изменения.

Новые версии устанавливаются и обновляются через HACS.

## Безопасное обновление

1. Обновить компонент через HACS.
2. Обновить страницу Home Assistant с очисткой кеша.
3. Проверить расчёт, настройки, материалы, склад, заказы и историю.
4. При необходимости восстановить данные из JSON-резервной копии.
