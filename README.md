# Home Assistant 3D Print Calculator

Полнофункциональный 3D-калькулятор для Home Assistant: себестоимость печати, коммерческая цена, скидки, срочные заказы, материалы, склад и профили принтеров.

## Возможности

- расчёт себестоимости 3D-печати;
- учёт материала и отходов;
- учёт времени печати;
- электричество, амортизация и расходники принтера;
- упаковка, постобработка и труд;
- розничная цена;
- постоянный клиент со скидкой;
- оптовые скидки по диапазонам количества;
- срочный заказ с дополнительной надбавкой;
- минимальная стоимость заказа;
- округление цены вверх;
- управление материалами;
- складской остаток в граммах и катушках;
- списание материала после расчёта;
- профили принтеров;
- экспорт и импорт данных JSON;
- автоматическое сохранение данных в браузере;
- копирование полного расчёта и цены для клиента.

## Установка через HACS

1. Откройте **HACS → Frontend**.
2. Нажмите `⋮` → **Custom repositories**.
3. Добавьте репозиторий:

```text
https://github.com/menfis911/hassio-3d-print-calculator
```

4. Тип репозитория: **Dashboard**.
5. Установите **3D Print Calculator**.
6. Перезапустите Home Assistant или обновите страницу с очисткой кеша.

### Подключение к `panel_custom`

```yaml
panel_custom:
  - name: three-d-print-calculator
    sidebar_title: 3D Калькулятор
    sidebar_icon: mdi:printer-3d
    url_path: 3d-print-calculator
    module_url: /hacsfiles/hassio-3d-print-calculator/hassio-3d-print-calculator.js
```

## Данные

Настройки, материалы, склад и параметры расчёта сохраняются в браузере через `localStorage`.

При обновлении через HACS существующие данные должны сохраняться.

Для совместимости с ранее сохранёнными данными приложение поддерживает перенос существующего хранилища на актуальный ключ. Пользовательские настройки при обновлении не должны сбрасываться.

## Коммерческая логика

Значения по умолчанию:

- розница: наценка 70%;
- постоянный клиент: скидка 15%;
- опт 2–4 шт.: скидка 5%;
- опт 5–9 шт.: скидка 10%;
- опт 10–49 шт.: скидка 20%;
- опт от 50 шт.: скидка 30%;
- срочный заказ: +30%;
- минимальный заказ: 500 ₽;
- округление: вверх до 50 ₽;
- отходы: 5%.

Все параметры можно изменить в настройках калькулятора.

## Версионирование

Проект использует GitHub Releases и semantic versioning.

Формат версий: `MAJOR.MINOR.PATCH`.

- `PATCH` — исправления и небольшие изменения без изменения концепции;
- `MINOR` — новые функции и возможности;
- `MAJOR` — крупные изменения архитектуры или несовместимые изменения.

Новые версии устанавливаются и обновляются через HACS.

## Разработка

Основной файл проекта:

```text
hassio-3d-print-calculator.js
```

HACS использует его как frontend entrypoint.

Репозиторий не хранит отдельную копию JavaScript-файла в `www/`: это исключает расхождение между несколькими версиями одного и того же исходника.

## Безопасное обновление

1. Выпустить новую версию GitHub Release.
2. Дождаться появления обновления в HACS.
3. Обновить компонент через HACS.
4. Обновить страницу Home Assistant с очисткой кеша.
5. Проверить расчёт, настройки, материалы, склад и экспорт/импорт.
6. При необходимости вернуть предыдущий GitHub Release через HACS.
