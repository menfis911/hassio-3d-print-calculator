# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## [1.0.1] - 2026-09-10

### Fixed

- HACS entrypoint теперь содержит полный рабочий JavaScript-файл калькулятора.
- Исправлена упаковка frontend-файла для установки через HACS.
- Стабильная логика калькулятора V5.1 не изменялась.

### Migration

- Локальная версия в `/config/www/` не изменяется.
- Используется тот же ключ `ha-3d-print-calculator-v2`.
- Миграция выполняется параллельно до полной проверки HACS-версии.

## [1.0.0] - 2026-09-10

### Added

- Первый отдельный GitHub-репозиторий калькулятора.
- Перенесена стабильная рабочая версия 3D-калькулятора V5.1.
- Расчёт себестоимости материала с учётом отходов.
- Учёт времени печати и стоимости эксплуатации принтера.
- Коммерческое ценообразование.
- Розница.
- Постоянный клиент со скидкой.
- Оптовые скидки по количеству.
- Срочный заказ.
- Минимальная стоимость заказа.
- Округление цены.
- Управление материалами и складом.
- Списание материала.
- Профили принтеров.
- Импорт и экспорт JSON.
- Копирование полного расчёта.
- Копирование цены для клиента.
- Автоматическое сохранение данных в `localStorage`.
