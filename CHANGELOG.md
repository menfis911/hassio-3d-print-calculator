# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## [1.6.0] - 2026-09-10

### Added

- Переработан блок «Результат»: итоговая цена, цена за штуку, себестоимость, прибыль и маржа теперь выделены визуально.
- Добавлена понятная расшифровка коммерческого расчёта: наценка, скидка, срочность, минимальный заказ и округление.
- Для упаковки, постобработки и работы добавлены пояснения прямо в калькуляторе.
- Явно указано, что упаковка, постобработка и работа задаются за одно изделие и умножаются на количество.
- Сохранены отдельные действия «Полный расчёт» и «Цена клиенту».
- Loader теперь дополнительно загружает UI-улучшения с тем же cache-busting механизмом.

### Changed

- HACS больше не ограничивает установку одним `hassio-3d-print-calculator.js`: loader и UI enhancements устанавливаются вместе с основным JS.
- `loader.js` загружает основной JS и enhancement-модуль с параметром версии, полученным из `VERSION`.
- Версия проекта повышена до `1.6.0`.

### Compatibility

- Существующие `localStorage`, материалы, принтеры, настройки, заказы и история не изменяются.
- Коммерческая формула расчёта не менялась.

## [1.5.2] - 2026-09-10

### Fixed

- Добавлен стабильный HACS loader (`loader.js`) для панели Home Assistant.
- Loader читает актуальную версию из `VERSION` без HTTP-кэша и загружает основной JS с versioned query-параметром.
- Обновление через HACS больше не зависит от старого кэша ES module для `hassio-3d-print-calculator.js`.
- `configuration.yaml` больше не требуется менять при каждом обновлении калькулятора.

## [1.5.1] - 2026-09-10

### Fixed

- Исправлен ввод числовых значений: поле больше не перерисовывается после каждой цифры, поэтому можно нормально вводить многозначные и дробные значения, использовать Backspace/Delete и вставку из буфера.
- Числовые поля калькулятора сохраняют введённое значение без потери фокуса и позиции курсора.
- Добавлено постоянное хранение заказов в `localStorage`.
- Заказы восстанавливаются после перезагрузки Home Assistant/страницы.
- Заказ требует минимум две позиции и хранит клиента, позиции, количество, материал, принтер, себестоимость, цену и прибыль.
- Добавлено полноценное редактирование и удаление сохранённых заказов.
- История расчётов сохраняется отдельно от заказов.
- Добавлены просмотр, повторное использование, печать и удаление записей истории.
- Экспорт JSON теперь включает материалы, принтеры, настройки, текущий расчёт, историю и заказы.
- Импорт JSON восстанавливает полный набор данных с совместимостью старой структуры.
- Печать расчёта и заказа открывает системный диалог печати, включая `Save as PDF`.
- Сохранение состояния выполняется без полного DOM-render при наборе числовых значений.
- Сохранён единый frontend-файл для HACS без возврата legacy `www/3d-calculator-v5.1.js`.

### Compatibility

- Сохранён ключ `ha-3d-print-calculator`.
- Сохраняется автоматическая миграция из `ha-3d-print-calculator-v2`.
- Существующие материалы, принтеры, настройки и текущий расчёт переносятся автоматически.

## [1.5.0] - 2026-09-10

### Added

- Управление материалами: создание, редактирование и удаление.
- Учёт остатка материала в граммах и катушках.
- Управление профилями принтеров.
- Расчёт стоимости часа работы принтера.
- Многострочные заказы с несколькими изделиями.
- Сводный расчёт себестоимости, цены и прибыли заказа.
- История сохранённых заказов и расчётов.
- Повторное открытие сохранённого расчёта.
- Печать заказа и вывод через системный диалог печати в PDF.
- Экспорт и импорт JSON.
- Браузерное событие `three-d-print-calculator-changed` для дальнейшей интеграции с Home Assistant.

### Changed

- Введён единый ключ хранения `ha-3d-print-calculator`.
- Добавлена автоматическая миграция данных со старого ключа `ha-3d-print-calculator-v2`.
- Пользовательские данные сохраняются при обновлении через HACS.
- Структура проекта использует один основной frontend-файл без дублирующих копий.
- Версия проекта хранится в отдельном файле `VERSION`.
- Release workflow использует единый источник версии.

### Compatibility

- Существующая коммерческая логика сохранена.
- Существующие материалы, принтеры, настройки и текущий расчёт переносятся автоматически.
- Локальный файл Home Assistant не затрагивается.
