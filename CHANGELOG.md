# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## [1.5.0] - 2026-09-10

### Added

- Управление материалами: создание, редактирование и удаление.
- Учёт остатка материала в граммах и катушках.
- Управление профилями принтеров.
- Расчёт стоимости часа работы принтера.
- Многострочные заказы с несколькими изделиями.
- Сводный расчёт себестоимости, цены и прибыли заказа.
- История сохранённых заказов и расчётов.
- Повторное открытие сохранённого расчёта.
- Печать заказа и вывод через системный диалог печати в PDF.
- Экспорт и импорт JSON.
- Браузерное событие `three-d-print-calculator-changed` для дальнейшей интеграции с Home Assistant.

### Changed

- Введён единый ключ хранения `ha-3d-print-calculator`.
- Добавлена автоматическая миграция данных со старого ключа `ha-3d-print-calculator-v2`.
- Пользовательские данные сохраняются при обновлении через HACS.
- Структура проекта использует один основной frontend-файл без дублирующих копий.
- Версия проекта хранится в отдельном файле `VERSION`.
- Release workflow использует единый источник версии.

### Compatibility

- Существующая коммерческая логика сохранена.
- Существующие материалы, принтеры, настройки и текущий расчёт переносятся автоматически.
- Локальный файл Home Assistant не затрагивается.

## [1.0.2] - 2026-09-10

### Changed

- Приведена документация проекта к единому формату версий.
- Убраны внутренние обозначения предыдущих этапов разработки из пользовательского описания.
- README обновлён для HACS-установки.
- Убрана дублирующая копия JavaScript-файла из структуры проекта.

## [1.0.1] - 2026-09-10

### Fixed

- HACS entrypoint содержит полный рабочий JavaScript-файл калькулятора.
- Исправлена упаковка frontend-файла для установки через HACS.

## [1.0.0] - 2026-09-10

### Added

- Первый отдельный GitHub-репозиторий калькулятора.
- Расчёт себестоимости материала с учётом отходов.
- Учёт времени печати и стоимости эксплуатации принтера.
- Коммерческое ценообразование.
- Розница.
- Постоянный клиент со скидкой.
- Оптовые скидки по количеству.
- Срочный заказ.
- Минимальная стоимость заказа.
- Округление цены.
- Управление материалами и складом.
- Списание материала.
- Профили принтеров.
- Импорт и экспорт JSON.
- Копирование полного расчёта.
- Копирование цены для клиента.
- Автоматическое сохранение данных в браузере.
