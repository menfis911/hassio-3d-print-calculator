# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## [1.9.0] - 2026-09-11

### Added

- Добавлена локальная база клиентов: имя, контакт и привязка клиента к текущему расчёту.
- Добавлена история последних сохранённых расчётов по клиентам с количеством, ценой и прибылью.
- Клиента можно выбрать из списка или создать прямо из калькулятора.
- Клиент теперь выводится в коммерческий PDF.
- Коммерческий PDF переработан: дата, клиент, тип клиента, скидка, материал, принтер, количество, отходы, вес, время, упаковка, постобработка, себестоимость, цена и итог.
- В PDF добавлена краткая расшифровка формирования цены.
- Добавлено понятное объяснение реального энергопотребления Bambu Lab X1 Carbon + AMS.
- Для X1 Carbon автоматически предлагается рабочее значение `0.15 kWh/h` (≈150 Вт), если расход не задан.
- Для тарифа `10.25 ₽/kWh` это соответствует примерно `1.54 ₽/ч` электроэнергии.

### Changed

- Блок принтеров теперь показывает не только формулу, но и практическое значение для X1 Carbon + AMS.
- Электроэнергия учитывается в себестоимости через связку `kWh/h × тариф`, а не как декоративное поле.
- Добавлен отдельный JavaScript-модуль бизнес-функций и отдельный модуль коммерческого PDF.
- Версия проекта повышена до `1.9.0`.

### Notes

- Значение `150 Вт` — рабочее среднее для коммерческого расчёта, а не максимальная мощность X1 Carbon.
- Реальные измерения X1C с двумя AMS показывают примерно `103–135 Вт` во время печати; при нагреве возможны кратковременные значительно более высокие пики.
- Для максимально точной себестоимости рекомендуется позже заменить 0.15 kWh/h на фактическое измерение конкретной связки принтер + AMS.

## [1.7.1] - 2026-09-11

### Added

- Автосинхронизация количества постобработки с количеством изделий до ручного изменения.
- Возможность вручную установить количество постобработки, включая `0`.
- Добавлены «Новый расчёт» и «Дублировать».
- В PDF постоянного клиента выводится отдельной строкой скидка `−15%` или актуальная ставка.
- Отходы отображаются отдельной строкой в расчёте и PDF.
- В настройках добавлена расшифровка формул расчёта мелким текстом.
- В блоке принтеров добавлена подробная расшифровка электроэнергии, амортизации и расходников.
- Добавлен тариф электроэнергии с пояснением его участия в расчёте.
- Добавлены шаблоны расчётов.

### Fixed

- Исправлен синтаксический конфликт между UI-модулями, вызывавший пустую страницу.

## [1.7.0] - 2026-09-11

### Added

- Шаблоны типовых расчётов.
- Дублирование текущего расчёта.
- Новый расчёт с сохранением выбранного материала и принтера.
- Улучшено отображение срочного заказа.
- Добавлены пояснения по формуле стоимости принтера.
